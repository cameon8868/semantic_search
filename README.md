# Как запустить?

Запустите **`start.bat`** — через 5–15 минут появится локальная ссылка:
**http://127.0.0.1:8000**

---

## Требования

- **Python 3.10+**
- **g++ (MinGW-w64)** — для сборки `tfidf.exe`
- **~1.5 ГБ** свободного места (для PyTorch и SBERT-модели)

---

## Что делает каждый файл?

### `main.py`
3D-визуализация расположения документов в векторном пространстве.  
Показывает, как статьи из корпуса распределены по трём главным компонентам TF-IDF-векторов.  
⚠️ Запускать **только после** `parsing.py` и `tfidf.exe`.

### `parsing.py`
Скачивает тестовые данные (статьи из русской Википедии) по 23 темам и сохраняет их в формате `.txt` в папку `wikipedia_docs/`.

### `requirements.txt`
Список Python-библиотек, использованных в проекте.

### `search_api.py`
**Сердце проекта.**  
Внутри — FastAPI-сервер, три режима поиска (TF-IDF, SBERT, гибрид) и сам запуск приложения.  
⚠️ Запускать **только после** `parsing.py` и `tfidf.exe`.

### `start.bat`
Набор команд для автоматического запуска проекта.  
По сути, **одного его достаточно** для запуска всей системы — кроме `main.py` (его нужно запускать вручную, активируя виртуальное окружение).

Скрипт `start.bat` автоматически:
1. Создаёт `venv` (если его нет)
2. Устанавливает зависимости из `requirements.txt`
3. Запускает `parsing.py` (если нет корпуса `wikipedia_docs/`)
4. Собирает `tfidf.exe` из `tfidf.cpp` (если нет g++)
5. Запускает `tfidf.exe` (если нет `vectors.json`)
6. Запускает FastAPI-сервер

### `tfidf.cpp`
C++-модуль, который ищет папку `wikipedia_docs/`, созданную `parsing.py`, перебирает все `.txt`-файлы и строит из них `vectors.json` — удобный для обработки `main.py` и `search_api.py`.

**Зачем это нужно:** векторы документов считаются **один раз** и сохраняются в JSON. Это ускоряет работу проекта — не нужно каждый раз пересчитывать TF-IDF заново.

### `web.html`
HTML-вёрстка веб-интерфейса для `search_api.py`.  
Содержит поле ввода запроса, селектор режима поиска (TF-IDF / SBERT / Гибрид) и вывод результатов.
